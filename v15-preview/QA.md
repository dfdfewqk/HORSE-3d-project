# HORSE RANCH V15 — 실제 GLB 기반 1차 후보

## 적용 범위
- 기준: main `56dfebe4e429f1c8974018b1e6e05c826f9840df`, V14 웹 뷰어와 소스는 변경하지 않음.
- `v15-motion.js`: V14에서 4개 19채널 클립을 복사해 몸통 높이, 몸통 피치,
  목, 머리, 꼬리 본에 소폭의 주기적 추가 움직임을 적용한다. 앞/뒷다리의
  원래 곡선을 임의로 바꾸지 않는다.
- `v15-hair.js`: 실제 GLB의 기존 HairKey 갈기/꼬리 리본 메시의 UV V값에 따라
  털 뿌리는 고정하고 끝만 부드럽게 움직인다. CPU 폴백 또는 WebGL2 버퍼 서브업로드를 사용.
  이는 **가벼운 위상 기반 지연 효과**이지 물리 엔진이나 Blender Hair Dynamics 재현이 아니다.
- `v15-skin-qa.js`: 실제 GLB의 고정된 앞·뒷다리 검사 집합으로 V14와 V15의
  각 160프레임 신장도를 비교한다.
- `index.html`: 기존 `legacy-v7.html`을 iframe으로 재사용,
  정지/Walk/Cruise/Fast/Sprint 5개 선택 항목과 기존 카메라/재생 UI를 보존.

## 실제 검증 기록 (2026-10-16)
- GitHub 원본 GLB 8,689,100 bytes를 읽어 적용.
- 원본 스킨 관절 19개와 V13.4 배 부위 보정 정점 440개 유지 확인.
- 실제 기존 V12~V14 의존성 스크립트 실행 후 V15 4개 클립 생성,
  각 19개 채널 및 유한 수치, 5개 선택 항목 검사 통과.
- 별도 HairKey 자료: 갈기 primitive 2와 4, 꼬리 primitive 3, UV 뿌리 V=0.
- 기존 UV를 이용한 속도별 털끝의 소폭 움직임 발생, 정지에서는 0.
- CPU 스키닝 160프레임 / 클립, 실제 GLB 몸통 정점 24,314개,
  고정 뒷다리 모서리 2,932개, 앞다리 모서리 3,107개로 검증.

## 미완료 / 후속 검증
- **실제 Windows Chrome WebGL2 시각 재생, 조작 UI, FPS 실측 미완료.**
- 발굽 지면 접지, 미끄러짐, 정교한 관절 착지 타이밍 검증 미완료.
- 19본 리그에는 독립 Pelvis/Hoof 본이 없어 정교한 보행 한계가 남는다.
- 갈기와 꼬리의 개별 부착/충돌과 물리 역학은 간이 움직임으로만 구현.
- 앞다리 최대 1.5배 신장 초과 모서리 20개 미해결.
- 이번 CPU QA는 몸통 메시 피부 신장 비교이며 갈기·꼬리 전체 정점
  스키닝 안전성의 완전한 보증이 아니다.

개발자 QA: 미리보기 주소에 `?audit=1`을 덧붙이면 실제 GLB의
160프레임 전신 수치 검사를 실행한다. 이 값은 GPU 화면 검사가 아니다.
