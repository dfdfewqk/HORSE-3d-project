# HORSE RANCH V13.4 — hind-limb skin correction (2026-10-15)

Base: V13.2 restored main `c64b58e16c524b80a890997c27dcad4a2bd612d3`.
Source: actual deployed `legacy-v7.html` from the GitHub Pages artifact for this exact commit (19 skin joints, 24,314 body vertices, 40,506 body triangles).

## Confirmed problem and fix
V12 `editBelly` applied the broad abdomen torso-weight override as far out as |x|=0.245 model units in the hind-limb region. Real hind stifle/hock vertices at |x| about 0.19 and y about 0.65 were therefore spuriously pulled toward Torso during Gallop. V13.3 incorrectly tried to move the stifle pivot and was rolled back.

V13.4 changes ONLY the hind part of the V12 abdominal weight envelope to `1 - smoothstep(0.04,0.10,abs(x))`; fore-belly envelope stays unchanged. It neither alters joint pivots nor inverse-bind matrices, nor gait samples. Original V13.2 6-channel bounded Gallop stays selected. V12 belly-corrected vertex count in the real browser decreases from 1,040 to 440, deliberately excluding hind-leg skin while preserving the central belly strip. Both shared body parts still receive the updated weights via V13.1.

## Measured on current deployed GLB, 160 Gallop samples
Selection: physically connected triangle edges between vertices with >50% hind influence, y<0.95, z<-3.10, rest edge lengths 0.008–0.12.
- Maximum edge stretch ratio: V13.2 = 3.608; V13.4 candidate = 1.421.
- 99th percentile of per-edge max ratio: V13.2 = 2.149; V13.4 candidate = 1.260.
- Edges with max stretch >1.5: V13.2 = 152; V13.4 candidate = 0.
- Pelvic central-belly edge metric remains about 1.37 max at the same sampled region.

## Local browser tests
The exact legacy GLB was rendered in Chromium's actual 2D software fallback (not static placeholder images). Side/rear views of V13.2 versus candidate were inspected at 0.10, 0.35 and 0.57 second playback positions. No JavaScript errors. Also tested 20 paused sample evaluations across Gallop V13.2, Walk V13.1, original Trot, original Canter and Gallop V12. All loaded; two co-located body mesh primitives synchronized; 6 hind Gallop channels preserved. JavaScript source syntax checked.

## Limitations
Chromium test used the real CPU triangle skinning fallback; GPU WebGL renderer and user's PC require confirmation. This is a selective skin-weight correction of the temporary 19-joint preview, not restoration of the native 456-bone Blender rig. Naturalness of full gait, physical hoof contact and all viewing angles are not certified. If visibly worse, revert to base `c64b58e16c524b80a890997c27dcad4a2bd612d3`.
